# NetShield AI

## About
NetShield AI is an AI-powered network security project designed to monitor network activity and identify suspicious or abnormal behavior.

## Features
- Network monitoring
- Suspicious activity detection
- AI-based anomaly detection
- Real-time security analysis
- QR code support
- Flask-based web interface

## Technologies Used
- Python
- Flask
- Scikit-learn
- Psutil
- QRCode

## Project File
- netshield.py
- requirements.txt
